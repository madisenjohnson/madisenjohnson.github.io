Tools

Software and resources for studying molecular gas.

Visualization and analysis tools for studying molecular gas in astrophysical contexts.

01

Molecular Hydrogen Formation Analaysis Tool

This tool provides a framework for analyzing the formation of molecular hydrogen (H2) in various astrophysical environments. It allows users to input parameters such as density, radiation field strength, and cosmic ray ionization rates to model the atomic-to-molecular transition in interstellar gas. IN PROGRESS.

02

GMC Lifecycle Tool

This tool provides a framework for analyzing the lifecycle of giant molecular clouds (GMCs) in galaxies. IN PROGRESS.
